# 台灣休假日行事曆

一個現代化的台灣休假日查詢網站，使用純HTML、CSS和JavaScript開發，無需任何外部套件。

## 功能特色

- 📅 **完整休假日資料**：包含2024-2026年的台灣國定假日和傳統節日
- 🗓️ **例假日顯示**：自動生成週六、週日的例假日，可切換顯示/隱藏
- ⚠️ **值班標示**：根據「每4個休假日後第5個休假日值班」規則自動標示值班日
- 🔍 **智能搜尋**：可搜尋節日名稱和描述，包含值班日搜尋
- 📱 **響應式設計**：支援桌面和行動裝置
- 🎨 **現代化UI**：美觀的漸層背景和動畫效果
- 📊 **統計資訊**：顯示總休假日數、國定假日、傳統節日、例假日和值班日數量
- 👁️ **雙重檢視**：月份檢視和列表檢視
- 🎯 **互動體驗**：點擊節日查看詳細資訊，值班日有特殊提醒
- 🔄 **靈活控制**：可選擇是否顯示例假日

## 使用方法

1. 直接在瀏覽器中開啟 `index.html` 檔案
2. 使用年份導航按鈕切換不同年份
3. 在搜尋框中輸入關鍵字搜尋特定節日
4. 切換「月份檢視」和「列表檢視」來查看節日
5. 使用「顯示例假日」開關來控制是否顯示週六、週日
6. 點擊任何節日項目查看詳細資訊

## 技術特色

- **純原生技術**：僅使用HTML5、CSS3和ES6+ JavaScript
- **SVG圖標**：所有圖標都是SVG格式，支援高解析度顯示
- **CSS動畫**：流暢的過渡動畫和懸停效果
- **模組化設計**：清晰的代碼結構，易於維護和擴展
- **無依賴性**：不需要任何外部庫或框架

## 節日資料

網站包含以下類型的節日：

### 國定假日
- 中華民國開國紀念日
- 和平紀念日
- 兒童節
- 勞動節
- 國慶日
- 行憲紀念日

### 傳統節日
- 農曆春節（除夕至初五）
- 民族掃墓節（清明節）
- 端午節
- 中秋節

### 例假日
- 每週六、週日自動生成
- 可透過開關控制顯示/隱藏
- 包含完整的年度例假日統計

### 值班日
- 支援自定義值班日設定（目前設定：2025年10月12日為值班日）
- 根據「每經過4個休假日，下個休假日就要值班」的規則自動計算其他值班日
- **重疊處理**：當國定假日和例假日重疊時，只算作一個休假日
- 值班日會有明顯的視覺標示（紅色背景、警告圖標）
- 包含值班日統計和詳細資訊
- 支援搜尋「值班」關鍵字快速找到值班日
- 值班日會顯示備註資訊（指定值班日或規則計算）

## 自定義

您可以輕鬆修改 `script.js` 中的以下物件來自定義網站：

1. **節日資料**：修改 `taiwanHolidays` 物件來添加更多年份的節日資料
2. **值班日設定**：修改 `customDutyDays` 物件來設定特定的值班日
   ```javascript
   const customDutyDays = {
       '2025-10-12': { isDuty: true, dutySequence: 1, note: '指定值班日' }
   };
   ```

## 調試功能

網站提供了調試功能，您可以在瀏覽器控制台中使用：

- `checkDutyStatus('2025-10-12')` - 檢查特定日期的值班狀態
- `listAllDutyDays(2025)` - 列出指定年份的所有值班日
- `checkOverlappingHolidays(2025)` - 檢查指定年份的重疊情況
